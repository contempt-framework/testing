# contempt/testing

[![CI](https://github.com/contempt-framework/testing/actions/workflows/ci.yml/badge.svg)](https://github.com/contempt-framework/testing/actions/workflows/ci.yml)

Deterministic fakes and assertions for testing Contempt applications without booting a runtime.

> This repository is a **read-only split** of the Contempt monorepo.
> Issues and pull requests belong in
> [contempt-framework/contempt](https://github.com/contempt-framework/contempt).

## Installation

```bash
composer require contempt/testing
```
